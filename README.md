# Rock
This repository contains the source code for the subterranean device

Pin Out:
3v3 -> VCC for LoRa, SD Card, MS5837, and ADXL345
GND -> GND for LoRa, SD Card, MS5837, and ADXL345
D1 -> LoRa RST
D2 -> LoRa G0 (Interupt)
D3 -> LoRa Chip Select
D4 -> Shared SDA (MS5837 & ADXL345)
D5 -> Shared SCL (MS5837 & ADXL345)
D6 -> SD Card Chip Select
D7 -> MISO Bus
D8 -> CLK Bus
D10 -> MOSI Bus
