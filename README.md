# Rock
This repository contains the source code for the subterranean device

Pin Out:
3v3 -> VCC for LoRa, SD Card, MS5837, and ADXL345\n
GND -> GND for LoRa, SD Card, MS5837, and ADXL345\n
D1 -> LoRa RST\n
D2 -> LoRa G0 (Interupt)\n
D3 -> LoRa Chip Select\n
D4 -> Shared SDA (MS5837 & ADXL345)\n
D5 -> Shared SCL (MS5837 & ADXL345)\n
D6 -> SD Card Chip Select\n
D7 -> MISO Bus\n
D8 -> CLK Bus\n
D10 -> MOSI Bus
